Aqui está a lista detalhada e o modelo padrão (JSON) que você pode usar para preencher os dados.

📋 Campos da Empresa (Negócio/Profissional)
Esses são os dados referentes ao local ou serviço prestado:

Obrigatórios:

name: Nome da empresa ou do profissional (Ex: "João Pinturas").
latitude: Latitude exata para o mapa (Ex: -23.550520).
longitude: Longitude exata para o mapa (Ex: -46.633308).
Opcionais (mas muito recomendados):

category: Categoria do serviço (Ex: "Manutenção", "Restaurante", "Saúde").
phone: Telefone de contato comercial (Ex: "+5511999999999").
address: Endereço em formato de texto (Ex: "Rua das Flores, 123, Centro").
longDescription: Uma descrição mais longa sobre o que a empresa faz.
logoUrl: Um link para a foto de perfil/logo da empresa (Ex: "https://site.com/logo.png").
n8nEndpointUrl: Caso esse cliente já tenha um robô do n8n configurado, o link do Webhook dele.



🎁 Ofertas / Promoções 
Caso queira já cadastrar promoções junto com a empresa, você pode enviar uma lista offers dentro de cada empresa. Cada oferta pode ter:

title: Título da oferta (Ex: "10% de Desconto").
description: Descrição da oferta.
imageUrl: Link de uma imagem para a oferta.
rewardPoints: Pontos pro usuário (O padrão é 100).
